# Humanizer-zh-update: AI 写作去痕工具（中文更新版）

> **声明：**
> - 本项目的核心翻译自 [blader/humanizer](https://github.com/blader/humanizer) v2.9.1
> - 实用工具部分（核心规则、快速检查清单、质量评分）参考了 [hardikpandya/stop-slop](https://github.com/hardikpandya/stop-slop) 和 [op7418/Humanizer-zh](https://github.com/op7418/Humanizer-zh)
> - 原项目基于维基百科的 [Signs of AI writing](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) 指南

## 项目简介

Humanizer-zh-update 是一个用于去除文本中 AI 生成痕迹的工具，帮助你将 AI 生成的内容改写得更自然、更像人类书写的文本。

本项目基于英文原版 humanizer v2.9.1 的完整翻译，覆盖全部 **33 种** AI 写作模式。核心特性包括：禁止捏造事实规则（改写不得添加原文中不存在的事实）、信息优先于形式（取代段落对等）、语音样本优先于规则、三种调用模式（粘贴文本/文件/嵌入）、草稿-审计-终稿三轮工作流（含捏造检查）。

改写遵循禁止捏造规则：绝不添加原文中不存在的事实、名称、日期或引用。具体性必须来自原文或作者，而非来自改写。

本项目适用于：
- 编辑和审阅 AI 生成的内容
- 提升文章的人性化程度
- 学习识别 AI 写作的常见模式

## 安装

### 方法一：通过 npx 全局安装（推荐）

```bash
npx skills add https://github.com/Ttungx/humanizer-zh-update.git --global
```

全局安装使技能在所有项目中可用。省略 `--global` 则为项目本地安装，可提交并与协作者共享。安装后启动新的 Agent 会话或重新加载 skills。

### 方法二：Claude Code 插件

Claude Code 用户也可以作为插件安装：

```
/plugin marketplace add Ttungx/humanizer-zh-update
/plugin install humanizer-zh-update@humanizer-zh-update
```

技能将以 `/humanizer-zh-update:humanizer-zh-update` 方式调用。

### 方法三：通过 Git 克隆

```bash
# 克隆到 skills 目录
git clone https://github.com/Ttungx/humanizer-zh-update.git ~/.claude/skills/humanizer-zh-update
```

### 方法四：手动安装

1. 下载本项目的 ZIP 文件或克隆到本地
2. 将文件夹复制到 skills 目录：
   - **macOS/Linux**: `~/.claude/skills/`
   - **Windows**: `%USERPROFILE%\.claude\skills\`

3. 确保文件夹结构如下：
   ```
   ~/.claude/skills/humanizer-zh-update/
   ├── AGENTS.md                        # Agent 维护指南
   ├── SKILL.md                         # 技能定义文件（中文版）
   ├── README.md                        # 说明文档
   ├── LICENSE                          # MIT 许可
   └── .claude-plugin/
       ├── plugin.json                  # Claude Code 插件清单
       └── marketplace.json             # 市场入口清单
   ```

## 使用

### 基础用法

```
/humanizer-zh-update 请帮我人性化以下文本：

[粘贴你的 AI 生成文本]
```

### 语音校准

提供你自己的写作样本来匹配个人风格：

```
/humanizer-zh-update

这是我的写作样本，用于声音匹配：
[粘贴 2-3 段你自己的写作]

现在人性化这段文本：
[粘贴 AI 文本]
```

技能会分析你的句子节奏、用词和习惯，然后将它们应用到改写中，而不是生成泛泛的"干净"输出。

### 使用场景示例

#### 场景 1：改写营销文案

**输入：**
```
坐落在风景如画的杭州市中心，这家咖啡馆拥有丰富的文化底蕴和令人叹为观止的装饰。
它作为城市咖啡文化的焦点，为顾客提供无缝、直观和充满活力的体验。
```

**输出示例：**
> 这家咖啡馆在杭州市中心开了三年，以手冲咖啡和老建筑改造的空间出名。

#### 场景 2：改写学术摘要

**输入：**
```
本研究深入探讨了机器学习在医疗诊断中的关键作用，突出了其在不断演变的医疗格局中的重要性。
此外，它为该领域的未来发展奠定了坚实的基础。
```

**输出示例：**
> 本研究分析了机器学习在医疗诊断中的应用，重点是肺癌早期筛查。研究使用了 2019-2023 年间 5000 例病历数据。

#### 场景 3：改写博客文章

**输入：**
```
人工智能不仅仅是一种技术，它是我们思考未来的方式的革命。
行业专家认为这将对整个社会产生持久影响。
```

**输出示例：**
> 我一直在想 AI 会怎么改变我们的工作方式。上周和几个做产品的朋友聊，有人觉得很兴奋，有人担心失业，大概率真相在中间某个无聊的地方。

## 检测的 AI 写作模式

本工具能够识别并修复 **33 种** AI 写作痕迹，分为五大类：

### 内容模式（6 种）

| # | 模式 | 改写前 | 改写后 |
|---|------|--------|--------|
| 1 | **意义夸大** | "标志着……演变史上的关键时刻" | "成立于 1989 年，是行政职能分散化的一部分" |
| 2 | **知名度堆砌** | "被 NYT、BBC、FT 引用" | 精简列表；仅保留有出处的上下文 |
| 3 | **-ing 式肤浅分析** | "象征着……反映了……展示了……" | 删除，或仅保留来源支撑的内容 |
| 4 | **宣传性语言** | "坐落在令人叹为观止的区域" | "是贡德尔地区的一座城镇" |
| 5 | **模糊归因** | "专家认为它发挥至关重要的作用" | 指名真实来源或删除该主张 |
| 6 | **公式化挑战** | "尽管面临挑战……继续蓬勃发展" | 保留有出处的事实；删除吹嘘 |

### 语言和语法模式（7 种）

| # | 模式 | 改写前 | 改写后 |
|---|------|--------|--------|
| 7 | **AI 词汇** | "此外……持久……格局……展示" | "也……仍然常见" |
| 8 | **系动词回避** | "作为……设有……拥有" | "是……有" |
| 9 | **否定式排比/尾部否定** | "不仅仅是 X，而是 Y"、"……，没有猜测" | 直接陈述观点 |
| 10 | **三段式法则** | "创新、灵感和洞察" | 使用自然数量的项目 |
| 11 | **同义词循环** | "主人公……主要角色……中心人物……英雄" | "主人公"（最清晰时重复） |
| 12 | **虚假范围** | "从大爆炸到暗物质" | 直接列出主题 |
| 13 | **被动语态/无主语** | "不需要配置文件" | 明确行为者 |

### 风格模式（12 种）

| # | 模式 | 改写前 | 改写后 |
|---|------|--------|--------|
| 14 | **破折号/连接号** | "机构——不是人民——仍在继续——" | 全部删除：句号、逗号、冒号或括号 |
| 15 | **粗体过度使用** | "**OKR**、**KPI**、**BMC**" | "OKR、KPI、BMC" |
| 16 | **内联标题列表** | "**性能：** 性能得到提升" | 转换为散文 |
| 17 | **标题大写** | "Strategic Negotiations And Partnerships" | "Strategic negotiations and partnerships" |
| 18 | **表情符号** | "🚀 启动阶段：💡 关键洞察：" | 删除表情符号 |
| 19 | **弯引号** | `said "the project"` | `said "the project"` |
| 26 | **连字符词对** | "跨职能、数据驱动、面向客户" | 在谓语位置去掉连字符 |
| 27 | **说服性权威套话** | "归根结底，真正重要的是……" | 直接陈述观点 |
| 28 | **路标式宣告** | "让我们深入探讨""以下是你需要知道的" | 直接从内容开始 |
| 29 | **碎片化标题** | "## 性能" + "速度很重要。" | 让标题自己工作 |
| 30 | **差异锚定写作** | "此函数是为了替代之前的方法而添加的" | 描述它的功能，而非变更了什么 |
| 31 | **人为制造的收尾句** | "它没有偏好。没有先验。没有怀旧。" | 使用变化的句子长度和具体观点 |
| 32 | **格言公式** | "对称是信任的语言" | 用具体观点替换公式 |
| 33 | **对话式修辞开场白** | "说实话？取决于……" | 去掉假装坦率的设置 |

### 交流模式（3 种）

| # | 模式 | 改写前 | 改写后 |
|---|------|--------|--------|
| 20 | **聊天机器人痕迹** | "希望这对您有帮助！请告诉我……" | 完全删除 |
| 21 | **截止免责声明** | "虽然细节在可用来源中有限……" | 找到来源或删除 |
| 22 | **谄媚语气** | "好问题！您说得完全正确！" | 直接回应 |

### 填充词和回避（3 种）

| # | 模式 | 改写前 | 改写后 |
|---|------|--------|--------|
| 23 | **填充短语** | "为了实现""由于……的事实" | "为了""因为" |
| 24 | **过度限定** | "可以潜在地可能被认为" | "可能" |
| 25 | **通用结论** | "未来看起来光明" | 删除该段；以具体事实结尾 |

## 与旧版中文翻译的区别

| 特性 | 旧版 (humanizer-zh) | 本版 (humanizer-zh-update) |
|------|----------------------|---------------------------|
| 对齐上游版本 | v2.8.2 之前 | **v2.9.1**（最新） |
| AI 写作模式 | 24 种 | **33 种**（完整覆盖） |
| 禁止捏造事实规则 | 无 | 有（改写不得添加原文中不存在的事实） |
| 信息优先于形式 | 无（段落对等） | 有（压缩无聊部分，展开重要部分） |
| 语音校准 | 无 | 有（样本优先于规则，包括破折号禁令） |
| 调用模式 | 无 | 有（粘贴文本/文件/嵌入） |
| 检测指南（误报排除） | 无 | 有（12 类误报 + 7 类人类写作特征） |
| 草稿-审计-终稿工作流 | 无（直接输出） | 有（三轮迭代 + 捏造检查） |
| 完整示例 | 简短软件更新示例 | 里斯本旅行（含草稿/审计/终稿三轮） |
| 被动语态模式 (#13) | 无 | 有 |
| 新增风格模式 (#26-33) | 无 | 有（连字符词对、说服性权威、路标宣告、碎片化标题、差异锚定、人为收尾、格言公式、修辞开场白） |
| 核心规则速查 | 有（来自 stop-slop） | 保留 |
| 快速检查清单 | 有 | 保留 |
| 质量评分表 | 有（5 维度 × 10 分） | 保留 |
| 中文适用性标注 | 有 | 保留并更新 |

## 常见 AI 词汇警示列表

以下词汇在 AI 生成的中文文本中出现频率异常高：

- 此外、实际上、至关重要、深入探讨、强调
- 持久的、增强、促进、获得、突出
- 相互作用、复杂/复杂性、关键（形容词）
- 格局（抽象名词）、关键性的、展示
- 织锦/画卷（抽象名词）、证明、凸显
- 宝贵的、充满活力的、蓬勃发展的、不可或缺的
- 与……保持一致、致力于、坐落于
- 位于……的中心、开创性的、令人叹为观止的

## 完整示例

*（说明：下面的改写中添加的具体信息，如月份和街区名称，代表的是作者本应提供的细节。在真实会话中，这些来自用户；技能会询问而非捏造。）*

**改写前（AI 味道）：**
> 我最近度过了难忘的五天在里斯本，让我告诉你——这座城市完全偷走了我的心。从我到达的那一刻起，我就知道我到了一个真正特别的地方。
>
> 坐落在特茹河沿岸，里斯本作为葡萄牙永恒精神的充满活力的见证，丰富的历史和现代活力在每个角落交织。是的，著名的山丘很有挑战性——我的腿当然感受到了！——但每一次攀登都会回报你令人叹为观止的全景，让一切都值得。
>
> 不乘坐标志性的 28 路电车，旅程就不完整，它蜿蜒穿过城市最具历史意义的街区。还有美食？简直神圣。贝伦蛋挞店的原始蛋挞是深受喜爱的国宝，品尝一个还温热的蛋挞是我永远不会忘记的时刻。
>
> 但真正让里斯本特别的不仅仅是景点——而是那种感觉。离开主广场走几步，你会发现一个更安静、更真实的一面：阳光沐浴的小巷、迷人的瓷砖外墙和友好的当地人过着日常生活，邀请你慢下来品味每一刻。
>
> 当然，必看的圣乔治城堡提供了俯瞰下方屋顶的壮丽景色。队伍可能很长，但对于任何历史爱好者或好奇的旅行者来说，这种体验绝对值得。
>
> 我会再去吗？当然。里斯本不仅仅是一个值得参观的地方——它是一个值得一次又一次爱上的地方。如果你正在梦想下一次度假，这是一个承诺留下终身记忆的目的地。✨

**改写后（人性化）：**
> 去年十月我在里斯本待了五天，至今仍有些复杂感受。美，是的。也比任何人警告我的更伤膝盖。
>
> 山丘就是整个故事，而且不知怎么从不出现在宣传册里。我在阿尔法马的酒店，拍出来很好看，实际意味着每次想喝咖啡都要爬一段感觉有六层楼高的楼梯。到第二天我的小腿已经有意见了。我开始围绕哪个方向是下坡来规划每次出行，这是看一座城市的奇怪方式，但大概是诚实的方式。
>
> 每个人都说要坐 28 路电车，所以我坐了，挤在一个陌生人的背包旁四十分钟，三个旅行团在拍同一个角落。下次我会步行这条路线，或者早餐前去。不过蛋挞确实名不虚传。我在格拉萨一家普通的小店吃了一个，还是温热的，大约三十秒的时间里我理解了为什么有人围绕蛋挞规划旅行。
>
> 我没有预料到的是城市远离主广场后有多安静。从任何广场往上坡走两个街区，就变成晾衣绳、斑驳的瓷砖、敞开的窗户和把音量调大的老人看足球。那就是我一直想着的里斯本，不是城堡。
>
> 城堡还行。景色很好，队伍很长，我花在排队挪向入口的时间比进去后看任何东西的时间都多。如果我只有两天，我会把它换成一个下午的迷路。
>
> 我会再去，但要选春天，带双好鞋。里斯本不会为了让你舒服而特别迁就你。我想我喜欢这一点，即使我的腿不同意。
